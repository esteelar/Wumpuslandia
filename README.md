# Wumpuslandia
Trabajo de IA - Se tiene que pasar niveles de Geometry Dash de forma autónoma. Para ello programamos un agente dotado de un algoritmo de aprendizaje por refuerzo (SARSA con trazas de elegibilidad) que sea capaz de superar los niveles de manera optima.

Usamos como juego esta copia de Geometry Dash porque podemos obtener el estado interno del agente dentro del mundo y está hecho en python:
https://github.com/AnshSingh16/Geometry_dash_clone_game
